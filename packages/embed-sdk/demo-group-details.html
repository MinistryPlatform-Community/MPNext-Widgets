Group Details & Sign-up

Full group detail view with a tabbed Contact-the-Group (inquiry) and Sign-up flow.

<next-group-details>
Contacting a group (inquiry) works anonymously. Signing up for a group requires sign-in so the participant can be attached to your contact record.
Sign in (required to sign up; pre-fills your household members)

Initializing widget...

Widget CodeAdd this to any page where you want this widget

<!-- Group id can come from this attribute or the URL ?id= -->
<next-group-details
  group-id="1234"
  return-url="/groups"
  show-full-address="true"></next-group-details>

<script>
  const w = document.querySelector("next-group-details");
  w.addEventListener("groupDetailLoaded", (e) => console.log("Loaded:", e.detail));
  w.addEventListener("inquirySubmitted", (e) => console.log("Inquiry sent:", e.detail));
  w.addEventListener("signupSubmitted", (e) => console.log("Signed up:", e.detail));
  w.addEventListener("loginRequired", () => console.log("Sign in required"));
  w.addEventListener("groupDetailError", (e) => console.error(e.detail));
</script>
