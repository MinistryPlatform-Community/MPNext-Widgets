Unsubscribe

Landing page for the unsubscribe link in a bulk email. No sign-in: the recipient is identified by the link itself.

<next-unsubscribe>
This widget writes to MinistryPlatform the moment it mounts — that is the whole point (following the link must complete the opt-out; a confirm click is measurable drop-off on the one flow a sender is obliged to make easy). With a real Contact_GUID below it will set dp_Contact_Publications.Unsubscribed or Contacts.Bulk_Email_Opt_Out for that contact. Use a test contact, and use Undo to put it back.

“Load the link” navigates to ?cg=…&pubid=…, exactly as a recipient arriving from an email does. Leave the publication blank (or set 0) for the “stop all bulk email” path. The widget strips both parameters out of the address bar as soon as it has read them, so the GUID does not survive in history — that is why the boxes come back empty after a load.

Widget CodePut this on the page your unsubscribe links point at

<!-- Use the widget. No sign-in, no next-user-menu: the whole point is
     that it works for someone with no MP login. -->
<next-unsubscribe
  my-subscriptions-url="https://www.example.church/email-preferences">
</next-unsubscribe>

<!-- The page's origin MUST be in EMBED_ALLOWED_ORIGINS, or no token is
     minted and every visitor sees an error. This is setup failure #1. -->

<!-- Then add a footer to every bulk-email template in MP. MP generates
     no unsubscribe link of its own, so a church that skips this has no
     unsubscribe at all. `pubid` is hardcoded per template; escape the
     ampersand as &amp; inside MP's HTML editor. -->
<a href="https://www.example.church/unsubscribe?cg=[Contact_GUID]&amp;pubid=4">
  Unsubscribe from the Weekly Newsletter
</a>
<a href="https://www.example.church/unsubscribe?cg=[Contact_GUID]">
  Stop all bulk email
</a>

<!-- Optional: a church CMS that already owns ?cg= can rename the params -->
<next-unsubscribe cg-param="contact" pubid-param="publication"></next-unsubscribe>

<!-- Optional: show nothing at all about the address (default is masked) -->
<next-unsubscribe show-email="false"></next-unsubscribe>

<!-- Listen to events -->
<script>
  const widget = document.querySelector("next-unsubscribe");
  widget.addEventListener("unsubscribed", (e) => {
    console.log("Unsubscribed:", e.detail); // { scope, publicationId }
  });
  widget.addEventListener("resubscribed", (e) => {
    console.log("Undone:", e.detail);
  });
  widget.addEventListener("unsubscribeError", (e) => {
    console.error("Error:", e.detail);
  });
</script>
