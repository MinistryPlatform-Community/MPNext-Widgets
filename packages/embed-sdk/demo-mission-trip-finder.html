Mission Trip Finder

Public, filterable mission-trip search. Each card is a real link to the trip's details page, which is next-pledge-campaign.

<next-mission-trip-finder>

Expect an empty result list on the reference domain — that is correct behaviour

The reference domain has exactly three Pledge_Campaign_Type_ID = 2 campaigns and none of them can be returned by this finder, so the widget below is expected to render its empty state. It is not broken, and no campaign id has been pinned here in the hope that one appears.

  • 1 – "Sample Mission Trip": its event (1) ended 2018-12-31.
  • 3 – "MyChurch Test Mission Trip": its event (10) ended 2018-12-30.
  • 4 – "Tanzania Mission Trip 2024": its event (18) ended 2024-04-27, Allow_Online_Pledge is false, and Program_ID is null — excluded three times over, since the search inner-joins Programs.

To see cards here, a church needs a type-2 Pledge_Campaigns row with a Program_ID, Allow_Online_Pledge = 1, and a linked Event whose Event_End_Date is in the future. Maximum_Registrants is optional: leave it null or 0 for an uncapped trip, or set it to see the seats-left line and the red "Trip is full" badge.

Widget CodeAdd this to any page where you want this widget

<!-- Use the widget -->
<!-- Attributes: -->
<!--   campaign-type-id="2"  REQUIRED. Pledge_Campaign_Type_ID; 2 = "Mission Project/Trip". -->
<!--   target="/url"         REQUIRED. The page hosting <next-pledge-campaign>. -->
<!--   id-parameter-name     Query parameter the card writes; default "id". Must match -->
<!--                         the same attribute on next-pledge-campaign, which also -->
<!--                         defaults to "id" — so neither normally needs setting. -->
<!--   congregation-id       Filters on the PROGRAM's congregation (legacy behaviour). -->
<!--   ministry-id, program-id, keyword -->
<!--   show-full-trips       Default "true". "false" hides trips with no seats left. -->
<!--   max-results           Default 100. -->
<next-mission-trip-finder campaign-type-id="2" target="/missions/trip"></next-mission-trip-finder>

<!-- Only trips with seats left, for one campus's programs -->
<next-mission-trip-finder campaign-type-id="2" target="/missions/trip"
  congregation-id="1" show-full-trips="false"></next-mission-trip-finder>

<!-- Listen to events -->
<script>
  const widget = document.querySelector("next-mission-trip-finder");
  widget.addEventListener("missionTripsLoaded", (e) => console.log("Loaded:", e.detail.count));
  widget.addEventListener("missionTripSelected", (e) => console.log("Selected:", e.detail.campaignId));
  widget.addEventListener("missionTripFinderError", (e) => console.error("Error:", e.detail));
</script>
