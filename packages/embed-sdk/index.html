Widget Demo Library

Select a widget to view its interactive demo, test events, and copy embed code.

Prerequisites: Run pnpm dev in the project root to start the Next.js API backend on port 3000.
Widget auth mode checking… Set EMBED_AUTH_MODE (legacy | dual | hardened) in .env.local, or override just this origin with EMBED_AUTH_MODE_ORIGINS=http://localhost:5173=dual. See README “Widget Authentication”.

Adding a Widget to a PageJust drop the tag on any page

<!-- Just drop the tag on any page -- no extra scripts needed! -->
<next-full-calendar></next-full-calendar>

<!-- Multiple widgets work on the same page -->
<next-add-to-calendar event-id="12345"></next-add-to-calendar>
<next-user-menu></next-user-menu>
