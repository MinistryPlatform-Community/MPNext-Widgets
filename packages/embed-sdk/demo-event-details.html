Full event detail view with registration: product options, promo codes, custom forms, participant management, and checkout redirect.

Registration builds an invoice then redirects to checkout-url for payment — the payment/checkout itself is handled by a separate widget. Sign in via the User Menu to register as a known contact.

Widget CodeAdd this to any page where you want this widget

<!-- Event id can come from this attribute or the URL ?id= -->
<next-event-details
  event-id="1234"
  return-url="/events"
  checkout-url="/checkout"></next-event-details>

<script>
  const w = document.querySelector("next-event-details");
  w.addEventListener("eventDetailLoaded", (e) => console.log("Loaded:", e.detail));
  w.addEventListener("registrationSaved", (e) => console.log("Registered:", e.detail.guid));
  w.addEventListener("registrationError", (e) => console.error(e.detail));
  w.addEventListener("loginRequired", () => console.log("Sign in required"));
</script>
