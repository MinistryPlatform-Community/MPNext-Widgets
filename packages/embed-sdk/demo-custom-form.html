Custom Form

Standalone MinistryPlatform custom form — the same field engine used inside event registration.

<next-custom-form>
Provide a form-id (or form-guid) of a MinistryPlatform form. You can also pass it in the page URL as ?id=<id-or-guid> (or ?formId= / ?formGuid=). The form's fields, depends-on logic, and optional contact/address blocks render automatically.
Sign in (optional — autofills your info & links your response to your MP record)

Widget CodeAdd this to any page where you want this widget

<!-- Use the widget (form-id or form-guid; also reads ?id= / ?formId= / ?formGuid= from the URL) -->
<next-custom-form form-id="123"></next-custom-form>
<next-custom-form form-guid="00000000-0000-0000-0000-000000000000"></next-custom-form>

<!-- Listen to events -->
<script>
  const widget = document.querySelector("next-custom-form");
  widget.addEventListener("formLoaded", (e) => console.log("Loaded:", e.detail));
  widget.addEventListener("formSubmitted", (e) => console.log("Submitted:", e.detail));
  widget.addEventListener("formError", (e) => console.error("Error:", e.detail));
  widget.addEventListener("loginRequired", (e) => console.warn("Login required:", e.detail));
</script>
