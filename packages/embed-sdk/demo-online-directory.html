Authenticated member directory: search by name/phone/email, filter by family, with phone, birthday, map, and email-a-member actions.

Sign in (required — the directory is only available to authorized members)

Widget CodeAdd this to any page where you want this widget

<!-- Requires the signed-in user to have directory access -->
<next-online-directory></next-online-directory>

<!-- Pre-filter to a congregation and hide the address + birthday icons -->
<next-online-directory congregation-id="1" hide-address="true" hide-birthday-icon="true"></next-online-directory>

<!-- Listen to events -->
<script>
  const widget = document.querySelector("next-online-directory");
  widget.addEventListener("directorySearched", (e) => console.log("Results:", e.detail.count));
  widget.addEventListener("directoryEmailSent", (e) => console.log("Emailed:", e.detail.contactId));
  widget.addEventListener("directoryError", (e) => console.error("Error:", e.detail));
</script>
