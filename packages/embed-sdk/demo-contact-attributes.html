About Me

Self-service contact attributes: the congregant ticks the skills, gifts and occupations that apply to them, grouped by attribute type.

<next-contact-attributes>
Sign in (required — the widget reads and writes your own Contact_Attributes)

What you should see on the reference domain

Two attribute types have Available_Online = 1: Occupation (7 attributes) and Spiritual Gifts (11) — 18 checkboxes in total. The other three types (Personal Characteristics, Group Tags, Persona (Synthetic)) are offline and must never appear here.

  • Every signed-in user lands in the empty-state edit mode — the full grid, no Cancel button, Submit disabled until you tick something. That is correct, not a failure to load: no contact on the reference domain holds an attribute in a visible type.
  • Tick a box and Submit; the page re-renders from the server's recomputed payload into the view mode, with an Edit button.
  • Untick everything and Submit to get straight back to the empty state — removal end-dates the row, it never deletes it, so re-ticking reactivates the same row rather than adding a second one.
  • Rows in offline types are invisible to every read and every write here. Contact 3 (MPTrainer) holds an active "Allergies & Special Needs" row in an offline type, and saving from this widget must leave it untouched.

Widget CodeAdd this to any page where you want this widget

<!-- No attributes required. Which attributes are offered is controlled
     entirely by Attribute_Types.Available_Online in the Platform. -->
<next-contact-attributes></next-contact-attributes>

<!-- Force a language (otherwise the resolution ladder decides) -->
<next-contact-attributes lang="es"></next-contact-attributes>

<!-- Listen to events -->
<script>
  const widget = document.querySelector("next-contact-attributes");
  widget.addEventListener("contactAttributesLoaded", (e) => console.log("Loaded:", e.detail));
  widget.addEventListener("contactAttributesSaved", (e) => console.log("Saved:", e.detail));
  widget.addEventListener("contactAttributesError", (e) => console.error("Error:", e.detail));
</script>
